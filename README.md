## ADA-FLIX-FRONTEND

* Aplicação frontend simples que vai servir para requisitar o backend
* Localmente ficará disponível em http://localhost após execução do docker-compose
* Possível acionar os botões disponíveis na pagina para requisitar o backend nas tabelas do Data Mart geradas.
* Para que ela funcione com o proxy reverso requisitando corretamente o backend é necessário subir a aplicação do frontend e do backend via docker-compose em:
    * https://github.com/1133939/ada-flix-deploy

#### Como rodar
* Siga as instruções em:
    * https://github.com/1133939/ada-flix-deploy
